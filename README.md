
#  나는 누구인가?

> "기술의 표면 뒤에 숨겨진 구조와 원리를 탐구하는 창작자 입니다."

---

##  정체성과 가치관

**가치관**

* 가상 세계와 텍스트, 기호가 지닌 추상적 가치를 존중하며 그 안에서 새로운 가능성을 발견합니다.



**원리와 구조에 대한 집착**

* 서비스의 겉모습을 최우선적으로 생각하지만 내부 동작 알고리즘, 보안 구조, 네트워크 흐름을 분석하는 데 호기심을 느낍니다.
* 최신 고압축 미디어 코덱 (AV1, avif, OAR) 및 로컬 AI 환경 구축 등 도전을 지속합니다.




**데이터 주권을 지키는 시스템 구축**

* 외부 의존도를 낮추고 자신만의 인프라를 직접 설계하며 제어권을 확보하는 과정에서 보람을 얻습니다.
* 안정적이면서도 확장성 높은 개인 개발 환경을 꾸준히 확장해 나가고 있습니다.
